# Technical test for the company MUTA 
  
 
the following technologies were used:
- Bootstrap
- Sass
- Material UI
- Vanilla-tilt
- Axios
- React Icons
- Vitest

This is an application that uses the pokemon API (POKEAPI) to list and filter pokemon by name and type.
It shows the main characteristics of each one of the pokemon.
>[!NOTE]
>Prerequisites:

- Node.js: Ensure you have Node.js installed on your system. You can download it from the official Node.js website.
- React: This project is built with React vite, so you'll need to have knowledge of React and its ecosystem.

Setup:

1. Clone this repository to your local machine:
```
   git clone https://github.com/HeinerLandero/_technical-test-muta
```
2. Install project dependencies using npm:
  ```bash
   cd _technical-test-muta
   npm install
  ```

Development:

To start the development server, run the following command:
```
npm run dev
```
This will start the development server and open the portfolio in your default web browser. Any changes you make to the source files will be hot-reloaded, allowing for a smooth development experience.

Building for Production:

To build the project for production, run:
```
npm run build
```
This will generate a production-ready build of your portfolio in the build directory, which can then be deployed to a web server.
